# lineageguard SQL 列级血缘与变更影响追踪

数仓开发在发布列改名或删除前，导入元数据与 SQL 引用，系统解析列级边、检测依赖环和断链，并给出反向影响清单。

## 模块

- 元数据采信：DDL、JSON、字节序标记、坏行隔离。
- 类型格：类型值域、精度与可空性变化。
- 兼容判定：读者与写者方向的破坏等级。
- 字段映射：字段身份、别名链与重命名。
- 影响面：SQL 源列、环、断边与反向闭包。
- 版本批次：生效区间、陈旧提交与幂等重跑。
- 迁移清单：单一证据 CSV。

## 启动

```bash
docker compose up --build
```

浏览器打开 <http://localhost:18214/>。

## 测试

```bash
docker compose exec -T app pytest -q
```

核心反例包括：同一目标列由不同源列推导、视图依赖环、双向引用缺边、版本区间重叠和陈旧提交。
